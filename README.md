 # Xtream Panel

 Ein übersichtliches Web-Panel zur Verwaltung und Organisation von **autorisierten** IPTV- bzw. Streaming-Diensten.

 > **Hinweis:** Dieses Projekt ist ausschließlich für rechtmäßige Anwendungsfälle gedacht. Verwende es nur mit Inhalten, Streams und Zugangsdaten, für die du die erforderlichen Rechte besitzt.

 ## Funktionen

 - Verwaltung von Benutzern und Zugängen
 - Übersicht über autorisierte Streams und Dienste
 - Zentrale Konfiguration über ein Web-Interface
 - Für die eigene Infrastruktur und lokale Entwicklung geeignet

 ## Voraussetzungen

 - Eine aktuelle Laufzeitumgebung entsprechend der verwendeten Projekttechnologien
 - Zugriff auf eine Datenbank, sofern von der Anwendung benötigt
 - Eigene, rechtmäßig bereitgestellte Stream- und Zugangsdaten

 ## Installation

 ```bash
 git clone https://github.com/robinkutzner/xtream-panel.git
 cd xtream-panel
 bash ./install.sh
 ```
